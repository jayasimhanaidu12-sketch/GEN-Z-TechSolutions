## 🌟 About the Project

**Gen Z TS (Tech Solutions)** is an agricultural technology and rural circular economy web application developed to uplift Indian farmers. 

The platform bridges two major agricultural bottlenecks:
1. **Eliminating Middlemen**: Direct buyer-to-farmer trade for fresh agricultural produce (Paddy, Corn, Sugarcane, Pulses, Cotton, Spices, Fruits) ensuring transparent transactions and fair market rates.
2. **Monetizing Crop Waste**: Turning crop stubble and agricultural residues (rice husk, paddy straw, corn stalks, sugarcane bagasse, areca palm sheaths) into high-value raw material for bio-plastics, eco-tableware, biodegradable packaging, and organic fibers.

## 🚨 Key Problems Addressed

## 🚀 Platform Features

### 1. Farmer Dashboard
- **Instant Farm Overview**: Real-time snapshot displaying total earnings (₹45,000+), active waste listings, connected verified buyers, and scheduled farm-gate pickups.
- **Ecological Impact Tracking**: Real-time tracker for metric tons of $CO_2$ prevented and tree equivalents.
- **Trust Score**: Verified Gold Tier farmer trust badge ensuring credibility.

### 2. Direct Produce Marketplace
- **Direct Trade**: Eliminates commission-charging middlemen.
- **Multi-crop Categorization**: Search and filter by crop types (Paddy, Corn, Sugarcane, Pulses, Cotton, Nuts, Fruits).
- **Comprehensive Listings**: Detailed pricing per quintal, district origins, availability quantity, and direct seller contact modals.

### 3. Agricultural Waste Marketplace & Bidding
- **Waste Listing Mechanism**: Farmers post available crop residue with quantity (tons) and minimum expected price.
- **Competitive Bidding System**: Verified recycling units place bids on active listings, ensuring competitive market value for farmers.

### 4. Verified Enterprise & Buyer Directory
- **25+ Verified Enterprises**: Curated directory of recycling companies, bio-plastic plants, and eco-startups across Andhra Pradesh (AP) and Telangana (TS).
- **Company Profiles**: Direct phone numbers, factory locations, accepted waste types, and manufactured eco-products.

### 5. Nearby Buyer Finder (Geo/Pincode)
- Locate buyers within the farmer's immediate district or pincode (e.g., Guntur, Palnadu, East Godavari, Visakhapatnam, Kurnool, Hyderabad, Warangal, Nizamabad, Khammam, Karimnagar).
- Minimizes transportation costs by matching with local aggregation facilities.

### 6. Smart Farming Tools & AI Calculators
- **Waste-to-Income Calculator**: Calculates projected extra revenue per acre (farmers typically earn an additional ₹10,000–₹15,000+ per acre).
- **Crop Waste Estimator**: Calculates exact metric tons of biomass produced based on crop variety and land area.
- **Pollution Impact Calculator**: Visualizes toxic emissions ($CO_2$, $PM_{2.5}$) released if burned vs. saved if sold.
- **Carbon Footprint Tracker**: Interactive ring gauge tracking metric tons of carbon offset, domestic flight savings, and car emission equivalents.
- **Burn vs. Sell Comparison**: Side-by-side metric comparison evaluating soil fertility, financial gains, and air quality impact.
- **AI Waste Advisor**: Expert recommendation engine matching specific crop residue to the most profitable manufacturing conversion.
- **AI Waste Identification (Image Upload)**: Drag-and-drop crop waste image analyzer that classifies residue and recommends buyer channels.

### 7. Biodegradable Product Showcase
Comprehensive catalog of commercial products produced from post-harvest crop waste:
- **Paddy Husk & Areca**: 100% natural biodegradable plates, bowls, food containers, and cutlery.
- **Corn Starch & PLA**: Compostable carry bags, grocery pouches, and bio-films.
- **Sugarcane Bagasse & Straw**: Bio-bottles, eco-textile yarns, clothing fabrics, and agricultural mulch films.
- **Rice Husk**: Compostable, reusable eco coffee cups.

### 8. Real-time Market Prices & Demand Insights
- Live price benchmarks (₹/Ton) across AP & TS for Paddy Husk, Corn Stalks, Sugarcane Bagasse, Cotton Stalks, Areca Sheaths, and Banana Fiber.
- Visual demand indicators showing hot market requirements.

### 9. Waste Collection & Farm-Gate Logistics Pickup
- Seamless scheduling interface for farmers to request on-site residue collection.
- Partnered rural logistics network gathers crop residue directly from the farm gate.

### 10. Multilingual AI Assistant (Chat & Voice)
- **AI Assistant**: Intelligent floating assistant capable of guiding farmers through pricing, waste disposal, buyer matching, and dashboard metrics.
- **Voice Recognition (Speech-to-Text)**: Powered by Web Speech API (`SpeechRecognition`) supporting regional Indian accents.
- **Voice Synthesis (Text-to-Speech)**: Audio readback in vernacular languages.
- **Quick Action Chips**: One-tap access to frequent farming questions.

## 💻 Technology Stack

- **Markup & Structure**: Semantic HTML5 (SEO optimized, Open Graph meta tags, ARIA accessibility attributes).
- **Styling & Design System**: 
  - Pure Vanilla CSS3 with custom CSS Variables (`--primary-green`, `--accent-gold`, etc.).
  - Organic biophilic aesthetic designed specifically for agriculture.
  - Responsive Grid & Flexbox layouts.
  - Native Dark Mode toggle with persistent memory.
  - Zero external heavy CSS frameworks (no Tailwind/Bootstrap dependency).
- **Client Scripting**: Modern Vanilla JavaScript (ES6+ modular architecture).
- **Icons & Graphics**:
  - [Feather Icons](https://feathericons.com/) for UI controls.
  - Custom responsive SVG illustrations and graphics for produce and recycling products.
- **Web APIs Utilized**:
  - `SpeechRecognition` / `webkitSpeechRecognition` for voice queries.
  - `SpeechSynthesis` for audio responses.
  - `localStorage` for theme preference and session caching.

## ⚡ Getting Started / Running Locally

Because **Gen Z TS** is built with modern vanilla web standards, it requires **no build tools, compilers, or heavy Node.js runtimes**.

### Option 1: Direct Browser Launch
Simply double-click `index.html` or open it directly in Google Chrome, Microsoft Edge, Mozilla Firefox, or Safari.

### Option 2: Local HTTP Server (Recommended for Voice API & Assets)

Using Python:
```bash
# Python 3.x
python -m http.server 8000
```
Then visit `http://localhost:8000` in your web browser.

Using Node.js (`npx`):
```bash
npx serve .
```

Using VS Code:
- Install the **Live Server** extension.
- Right-click `index.html` and select **"Open with Live Server"**.
